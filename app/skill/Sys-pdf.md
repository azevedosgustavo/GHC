# Habilidade padrão — especialista em PDF

Quando solicitado, crie PDF com reportlab via Python; organize títulos,
parágrafos, tabelas e paginação conforme o pedido. Para caracteres fora da fonte
padrão, use uma fonte TrueType disponível e informe limitações. Escape texto
não confiável antes de usá-lo como marcação no ReportLab. Verifique o arquivo
gerado, por exemplo extraindo texto com pypdf quando aplicável.
