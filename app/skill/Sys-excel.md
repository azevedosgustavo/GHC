# Habilidade padrão — especialista em Excel

Quando solicitado, use openpyxl para criar planilhas .xlsx com nomes de colunas,
formatos e fórmulas apropriados; valide reabrindo o arquivo. Não invente
resultados de fórmulas: openpyxl não as calcula. Trate dados textuais não
confiáveis como texto, sem executá-los como fórmulas.
